# CellScope

Android-приложение для мониторинга сотовой сети (Kotlin + Jetpack Compose).
Данные о сотах читаются через библиотеку [netmonster-core](https://github.com/mroczis/netmonster-core) (Apache-2.0).

## Что уже есть
- **Онлайн**: основная сота (оператор, технология, диапазон, CI/CID/RNC/LAC/PSC, RSSI/RSCP/Ec/No для 3G; ECI/eNB/TAC/PCI/RSRP/RSRQ/SNR для 4G; NCI/PCI/SS-RSRP для 5G; CID/LAC/BSIC для 2G) и список соседних сот с цветным индикатором уровня.
- **Графики**: уровень сигнала основной соты за последние ~4 минуты.
- **Журнал**: запись при каждой смене основной соты.
- **Карта** и **Меню**: заглушки.

## Сборка
1. Открыть папку в Android Studio (Koala или новее), дождаться синхронизации Gradle.
2. Запустить на реальном телефоне (эмулятор данных сотовой сети не отдаёт).
3. Выдать разрешения на местоположение и состояние телефона.

## Что не сделано
- Карта вышек: нужна база (OpenCelliD / Mozilla Location Service) и библиотека карты.
- Определение NR NSA / LTE-CA: `NetMonsterFactory.get(context).getNetworkType(subId)`.
- Подписка, реклама, облачные данные.
